# The Franchise Wars v0.3.0 — Complete Native Foundry Release

This release converts the campaign from journal-first content into a runnable Foundry VTT v14 / D&D5e v6 campaign module while preserving the existing journals, scene, campaign systems and art.

## Included
- 372 managed native D&D5e Items: 337 franchise menu/products, 12 magic/corporate items, and 23 Receipts/evidence items.
- 272 Actor definitions/references: 92 bundled bespoke/recurring NPC Actors and 180 native D&D5e compendium clones for standard opposition and named combat NPCs.
- 300 bundled campaign art files.
- 121 managed Journal entries and 1 Scene(s).
- Idempotent importer for Journals, Items, Actors and Scenes.
- Correct stable manifest URL and versioned GitHub release download URL.
- Canonicalised the Murder King performer as Mortimer Pell across runtime campaign material.

## Install Manifest
`https://raw.githubusercontent.com/pacts-and-polyhedrals/franchise-wars/main/module.json`

## Release Asset
`franchise-wars-v0.3.0.zip`
