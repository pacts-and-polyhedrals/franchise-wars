# v1.1.5 — Map Links Work
- Map links in the journals ("map", "Open battlemap", the Battlemap Library and the Command Centre) are now green map buttons that always respond. Previously they were Foundry Scene links, which did nothing when clicked in v14.
- Click: view the battlemap (only you move; players stay where they are).
- Shift-click: activate the battlemap for everyone.
- If the battlemap isn't in the world yet, it is imported from the Battlemaps compendium (keeping its ID, so pins and tokens stay linked) and then opened.
- If it can't be found anywhere, you get a warning that says to re-import battlemaps, instead of nothing happening.

Includes everything in v1.1.4.
